# TOMORI LP（ローカル版）

TOMORIを紹介する1ページのLPです。デモURLが届くまでは公開しません。

## ファイル構成

```
index.html        ページ本体（文章はここ）
css/style.css     見た目（色は先頭の :root で変える）
js/config.js      差し替え用の設定（デモURL・画像・画像の説明）
js/main.js        config.js をページへ反映する処理（ふだん触らない）
images/           画像を置く場所
```

## ファーストビュー（ゲームのタイトル画面ふう）

- PC用：`images/tomori-game-front-desktop.webp`（1672×941・横長）
- スマホ用：`images/tomori-game-front-mobile.webp`（941×1672・縦長）
- 切り替え：画面幅767px以下はスマホ用、それより広い画面はPC用（`<picture>` で切り替え）。
- 画像は切り取らず、元の比率のまま幅いっぱいに表示する。
- ロゴ・キャッチ・「冒険をはじめる」・「開発中のプロトタイプ」は、画像に描きこみ済み。同じ文字をHTMLで重ねないでください。
- 緑のボタンの上には、透明な本物のリンクがあります。デモURLが未設定なら、行き先はページ下の「TOMORIを体験してみる」。
- ボタンの位置が変わる画像に作り直したときは、`css/style.css` の `.game-front__start-hitarea` の数値（左・上・幅・高さの%）も直す。PC用とスマホ用で数値は別です。
- 画像を読み込めなかった場合、見出しとボタンはふつうの文字で出る。
- 元のPNGは、リポジトリの外（`Downloads`）に保管。

## 画像は2種類に分けて扱う

- **コンセプト画像**（ファーストビュー・`seed`）：TOMORIの世界観を伝える絵です。画像の下に「コンセプトビジュアル」と小さく注記しています。
- **実際のアプリ画面**（`screenshots`）：アプリから撮ったスクリーンショットだけを入れます。

コンセプト画像を `screenshots` へ入れてはいけません。「実際のアプリ画面」と書いてよいのは、スクリーンショットだけです。

## 実際のアプリ画面を入れる

1. 届いた画像を、次の名前で `images/` に置く。

   | 順番 | ファイル名 | キャプション |
   |---|---|---|
   | 1 | `tomori-app-start.webp` | はじめの世界 |
   | 2 | `tomori-app-words.webp` | 写真から、言葉を見つける |
   | 3 | `tomori-app-adventure.webp` | ことばのタネが、世界をひらく |

2. `js/config.js` の `screenshots` で、置いた画像の `src` の `""` の中へ `images/ファイル名` を書く。
3. ブラウザで開き直して確認する。

画像の枚数に合わせて、並び方は自動で変わります。

- 0枚：「実際のアプリ画面」のセクションごと出ない
- 1枚：中央に大きく1枚
- 2枚・3枚：PCでは2列・3列、スマホでは1列

`src` が空のカードと、読み込めなかったカードはページに出ません。空の枠や「準備中」の表示も出ません。

縦横比は画像そのものに合わせて決まるので、変形も切り取りもしません。スマホの縦長画面もそのまま表示できます。
切り取って見せたいときだけ、`ratio`（例：`"16 / 9"`）と `position`（例：`"50% 30%"`）を書きます。

## デモURL

`js/config.js` の `demoUrl` に書きます。空のあいだはボタンがリンクにならず、「デモは準備中です」と表示されます。

## OG画像（SNSで共有したときの画像）

- 画像：`images/tomori-og.webp`（1200×630px）。`tomori-lp-hero.webp` から、ことばの樹と金色の道が入る右寄りの範囲を切り出したもの。元の画像は変更していません。
  `tomori-lp-hero.webp` は、いまはページに表示せず、OG画像の元として残してある。
- 設定：`index.html` の `<head>` に、コメントで設定場所を用意してあります。公開URLが決まったら、コメントの外へ出し、「公開URL」の部分を本当のURLに書き換えます。
- SNSは `https://` から始まる絶対URLしか読めません。公開前は設定しません。

## 守ること

- 外部のフォント・画像・解析タグを読み込まない（外部通信0件）。
- 問い合わせ先・住所・電話番号・メールアドレス・SNSは載せない。
- 製作者の表記は、画面では「こまたりゅうと」、description では「りゅうと制作」。勝手に漢字・ローマ字・敬称へ変えない。
